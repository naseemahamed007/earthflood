# 🌍 EarthFlood

### Earth Flood Detection and Early Warning Research Project

EarthFlood is a software-based project designed to explore rainfall data and support early flood-risk awareness.

## 🚀 Features

- 🌦️ Live weather forecast data
- 📊 Interactive rainfall charts
- 📍 Search for cities and towns
- 🗺️ Location map
- 📄 Download rainfall data as a CSV file
- 💻 Browser-based dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- Open-Meteo Weather API

## 💰 Project Cost

This prototype uses free tools and does not require special hardware.

## 🎯 Future Improvements

- Flood-risk estimation using historical rainfall data
- River-level monitoring where public data is available
- Machine learning for flood-risk research
- Improved alerts using verified data sources

## ⚠️ Disclaimer

EarthFlood is an experimental research prototype. Its rainfall forecasts are not official flood warnings, and rainfall alone cannot reliably predict flooding. Always follow local authorities during emergencies.
